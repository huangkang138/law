# 数据库表新增清单

统计时间：2026-07-16。

## 结论

| 口径 | 表数量 |
|---|---:|
| 项目初始 `sql/public.sql` | 54 |
| 当前 PostgreSQL `public` Schema | 77 |
| 净新增 | **23** |
| 其中业务表 | 22 |
| Alembic 管理表 | 1 |

统计方法：以 `sql/public.sql` 中的 `CREATE TABLE` 作为项目初始快照，以当前 PostgreSQL `information_schema.tables` 为现状；两边表名做差集。当前 77 张表均包含在初始 54 张与下列新增 23 张中，没有发现初始表被删除。

## 新增 23 张表

### 1. 数字人聊天：3 张

| 表名 | 对应内容 |
|---|---|
| `digital_human_sessions` | 数字人聊天会话，保存客户端、标题、启用状态和更新时间。 |
| `digital_human_messages` | 会话内的用户/助手消息，同时保存意图、情绪和置信度。 |
| `digital_human_requests` | 数字人请求幂等记录，防止同一个请求被重复执行。 |

### 2. Agent Runtime：6 张

| 表名 | 对应内容 |
|---|---|
| `matters` | 一个法律任务的案件工作区，保存目标、标题、客户端和会话归属。 |
| `agent_runs` | 一次可暂停、恢复的 Agent 运行；`state_json` 保存完整状态快照。 |
| `agent_steps` | Plan 中的持久化 Step，保存顺序、工具、审批要求、Observation、Verification 和 Decision。 |
| `tool_calls` | 每次工具调用及重试记录，保存输入、结果、错误和执行状态。 |
| `approval_requests` | 用户审批请求，保存审批状态、决定、有效期和所属客户端。 |
| `agent_audit_events` | Agent 状态变化审计事件，只记录动作摘要，不保存模型思维链。 |

### 3. Matter、材料、法域与法源：5 张

| 表名 | 对应内容 |
|---|---|
| `matter_jurisdictions` | Matter 的候选/已确认法域；保存国家、适用法律、法院、语言和生效时间。 |
| `agent_documents` | Matter 内已授权材料的文件信息、文本、哈希和解析状态。 |
| `document_fragments` | 材料分片及页码/字符偏移，供事实和证据精确定位。 |
| `legal_facts` | 从材料提取的候选事实，关联原文片段、位置、置信度和用户确认状态。 |
| `legal_authorities` | 法律来源及版本、有效期、内容哈希、可信等级、同步状态和新鲜度。 |

### 4. 劳动纠纷：2 张

| 表名 | 对应内容 |
|---|---|
| `labor_dispute_profiles` | 劳动纠纷确认事实、缺失字段、规则版本、流程状态和草稿审批状态。 |
| `agent_artifacts` | Agent 生成的可审阅交付物，例如仲裁申请书草稿及其证据/法源引用。 |

### 5. 版本化、幂等与可信运行：6 张

| 表名 | 对应内容 |
|---|---|
| `matter_fact_assertions` | Matter 确认事实的版本化断言，保存值、出处、原文和确认状态。 |
| `agent_plans` | 每次 Run 的 Plan revision，保存领域、模板版本、重规划原因、指纹和完整计划。 |
| `agent_run_actions` | Continue 操作的幂等记录，防止补信息、审批和重试被重复处理。 |
| `agent_event_outbox` | 与 Agent 状态事务一起写入的待发布事件，用于后续异步消费。 |
| `authority_sync_runs` | 官方法源同步批次，记录拉取、导入、未变化、待复核数量和失败信息。 |
| `authority_source_snapshots` | 官方法源原始响应快照，保存原始字节、哈希、URL、版本标记和验证状态。 |

### 6. 数据库迁移：1 张

| 表名 | 对应内容 |
|---|---|
| `alembic_version` | Alembic 当前迁移版本，不保存业务数据。 |

## 当前表来源说明

- 当前 69 张表有 SQLAlchemy ORM 声明。
- 7 张初始历史表只存在于 `sql/public.sql`/实库，当前没有 ORM 类：`contract_draft_messages`、`legal_document_draft_messages`、`legal_opinion_draft_messages`、`knowledge_graph_nodes`、`knowledge_graph_edges`、`knowledge_references`、`knowledge_relations`。
- `alembic_version` 由 Alembic 自动管理。
