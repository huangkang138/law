# 工作台

## 一级调用链

进入/恢复：前端 → POST /sessions（无 LLM）→ GET /workspace → 指针 → Matter → Triage → Run → Presenter → 前端原子 Hydration
切换/处理：PUT /workspace（版本 CAS）→ /agent/* → Facade（法域/材料/事实/分析/草稿）

## 一句话目的

完整事实、材料、法源、步骤与审批**只**在工作台处理——聊天只引导、工作台才处置实质内容。工作台有服务端权威的"当前案件"指针，刷新/切换会话后能确定性恢复；侧边陪伴数字人复用同一消息流与发送入口。

## 调用链

```text
进入工作台（未聊天）：
ensureWorkspaceSession → POST /sessions（无 LLM 创建空 Session + Workspace State 行）

恢复：
GET /sessions/{id}/workspace → get_context
→ 指针（行锁内）→ Matter → Triage → 最新 Run（updated_at/created_at 倒序）
→ Presenter 确定性投影（无 LLM，未知状态安全降级）
前端 loadSession：消息 + Workspace Context 并行取，单次提交（hydrationSequence 防迟到覆盖）

案件切换：
selectCurrentMatter → PUT workspace（expected_version CAS + Session 行锁；前端 workspaceSelectionTail 顺序队列）
同 Session 切换会使在途聊天失效（invalidateConversationRequest）

建案（工作台侧）：
POST /agent/matters（Idempotency-Key → sha256(client:key) 稳定 matter_id）
→ 失败重试复用同一 Matter；成功直接返回权威 Workspace 快照

实质处理（全部走 digital_human_agent 路由 + Facade）：
confirm_jurisdiction → add_material / organize → extract_material_facts（候选，用户采用）
→ update_labor_case_triage（补录事实）→ analyze_labor_dispute（期限/证据/法源验证）
→ create_labor_dispute_draft（仅用户明确审批 approved:true）
→ continue_task（结构化动作）/ resume_run（审批决定）

侧边陪伴：
DigitalHumanCompanion：store.messages 最近 4 条 + streamingMessage + ConversationComposer
→ 与主聊天同一个 sendMessage / 同一 Session / 同一 ConversationMessageContent 渲染
```

## 关键状态

| 状态 | 谁写 | 谁读 |
| --- | --- | --- |
| ConversationWorkspaceState（session_id 主键：active_matter_id + version） | select_matter / delete_matter / 懒初始化 | get_context / 后台建案 CAS |
| 前端 workspaceVersion / currentMatterId / currentTriage / currentAgentRun | applyWorkspaceContext / selectCurrentMatter | 工作台组件 / useLaborTriage 恢复 |
| laborContextBySession（仅运行期缓存，partialize 只存 sessionId） | sendMessage / loadSession | useLaborTriage |
| 权威业务状态：Matter / Triage / Run / 法域 / 事实 / 材料 / 草稿 | Facade | get_context 投影 |

## 判断点（已查过）

- **职责分离**：完整事实、材料、法源、步骤、审批按钮、导出只在工作台；聊天不显示模板 ID、英文状态、原始 JSON 与完整步骤。
- **指针权威**：localStorage 不能决定当前 Matter/Run（partialize 只保留 sessionId）；显式清空后不猜测旧案件。
- **一致性快照**：指针、版本、Matter、Triage、Run ID 在 Session 行锁保护的同一事务读取。
- **删除安全**：删除当前 Matter 在同一事务回退到最近活跃 Matter；衍生数据靠 FK 级联。
- **空状态语义**：无 Matter 返回空工作台（不是 404）；有 Matter 无 Triage/Run 时对应字段为 null，不误报故障。
- **越权**：Session/Matter/Run 全部校验 client_id，403 不返回任何摘要。
- **Presenter 边界**：只解释状态和下一步，不解释法律结论、不替代审批、不读模型思维链。
