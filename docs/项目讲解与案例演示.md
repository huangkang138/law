# 律知智能法律服务平台｜项目介绍与体验案例

本说明面向第一次接触律知的体验者。打开分享给你的平台链接后，可以先读“平台能做什么”，再挑选案例体验。全文案例中的人物、单位和事件均为虚构，请勿把演示结果用于真实案件。

## 一句话认识律知

律知把法律咨询、合同审查、案件与纠纷处理、文书起草、模拟法庭、知识图谱和常用法律工具放在同一个平台里。你可以从一个问题出发，先梳理事实，再根据需要使用不同功能。页面中的 AI 内容属于辅助分析，重要事实、法律依据和正式文书仍需要人核对。

## 平台能做什么

| 首页或顶部导航 | 可以完成的事 | 适合从哪里开始 |
| --- | --- | --- |
| **普法问答** | 与“法小助”多轮交流，梳理法律问题；按需要进入相应功能 | 还不知道该用哪个功能时，先描述遇到的事 |
| **合同审查** | 上传 PDF、Word 或图片合同，查看条款风险和修改建议；页面也有示例合同 | 手里已有合同，想先看哪些条款值得关注 |
| **法律检索** | 使用“法律案情推断”“相似法律文书”“相似案件解释”“法律意见咨询”四个入口 | 想分析案情、寻找参考材料，或按步骤整理法律意见 |
| **案件与纠纷** | “纠纷整理”梳理事实；“纠纷中心”分步查看证据、维权路径、文书和提醒；“案件工作台”持续办理劳动争议 | 问题已经形成纠纷，需要整理材料和下一步行动 |
| **文件起草** | 描述需求起草文书或合同，也可使用文书模板；起草结果需自行核对 | 已明确要写哪类文件、给谁用、包含哪些事项 |
| **模拟法庭** | 输入案情，体验原告、被告、法官视角的模拟对话；页面提供文字和语音模式 | 想从不同立场检查自己的陈述和争议焦点 |
| **法律图谱** | 查看和搜索知识图谱；在开放创建权限时，可建立图谱、节点和关系 | 想把法律概念、材料与关系整理成结构图 |
| **辅助工具** | 使用法律计算器、法律日历、诉讼时效查询及各类费用估算工具 | 已有明确金额、日期或事项，希望先做参考测算 |
| **历史记录** | 查找页面保存的部分咨询、分析或生成记录 | 想继续查看此前处理过的内容 |
| **其他开放页面** | 平台还有智能体管理、收藏和设置页面；是否向体验者开放以实际页面为准 | 需要查看已收藏内容，或由被授权人员管理智能体时 |

辅助工具菜单还包括诉讼费、工伤赔偿、律师费、合同违约金、保全费、执行费、遗嘱费、公告费、鉴定费和仲裁费等计算入口。不同工具所需参数由页面提示；结果是参考值，不能代替适用地区、时间和收费标准的核实。

## 第一次体验，推荐这样走

1. 在首页点 **普法问答**，输入一个下方案例中的问题，看看法小助怎样追问和解释。
2. 进入 **合同审查**，点击页面自带的“体验示例合同审查”，观察风险条款、说明和修改建议。
3. 用同一段虚构案情分别试 **法律案情推断**、**纠纷整理** 和 **相似案件解释**，比较它们各自给出的内容。
4. 进入 **文件起草**，用清楚的文件类型、当事人和要求试写一份草稿。
5. 想进一步体验时，再试 **模拟法庭**、**法律图谱** 和 **辅助工具**。

这些入口各自解决不同问题，不要求按固定顺序使用；下面的案例让你可以直接复制内容开始。

## 案例一：虚构租赁押金纠纷

这是一套可贯穿咨询、案情分析、纠纷整理、相似案件解释、文书起草和模拟法庭的演示材料。

### 先复制这段案情

```text
【完全虚构的体验案例】
测试承租人乙与测试出租人甲于2026年1月1日签订一年期房屋租赁合同，月租金2500元，押金3000元。双方约定退租并交还房屋后核对水电等费用，再处理押金退还。

2026年6月30日，双方协商提前退租。承租人乙交还钥匙，并拍摄了退租当天的房屋照片。出租人甲称房内一张椅子损坏，因此暂不退还3000元押金，但双方尚未核实椅子损坏时间、维修费用或其他应扣款项。

承租人乙希望查明押金应如何结算，并要求出租人甲说明扣款依据。现有材料线索包括租赁合同、3000元押金转账记录、退租照片和双方聊天记录。这里列出的材料只是虚构线索，并不代表文件已经上传。
```

### 用同一个案例体验各功能

| 去哪里 | 可以直接输入或选择什么 | 重点看什么 |
| --- | --- | --- |
| 普法问答 | “退租后房东说椅子坏了，一直不退押金。我该先核对哪些事实和材料？” | 是否解释需要核对的合同约定、交房情况、损坏证据和费用，而不是直接替双方下结论 |
| 法律案情推断 | 粘贴完整案情 | 是否区分双方说法、争议焦点、还缺的事实和可采取的下一步 |
| 相似法律文书 | “房屋租赁押金退还争议，想参考押金返还请求的文书写法。” | 返回的内容是否与你提供的事实相关；核对文书名称和具体条款 |
| 相似案件解释 | “房屋租赁到期或协商退租后，出租人主张损坏物品并扣押金，通常需要核对什么？” | 是否给出可供参考的分析，注意不要把相似情形当成本案结果 |
| 纠纷整理 | 粘贴完整案情 | 是否整理出当事人、时间线、双方主张、证据线索及待补充信息 |
| 纠纷中心 | 粘贴完整案情并从“纠纷整理”开始 | 依页面步骤查看取证提示、维权路径、文书和提醒等内容；逐项核对输入与输出 |
| 文件起草 → 文书起草 | “请根据上述虚构事实起草一份向出租人说明押金结算争议的沟通函，列明已知事实、待核对事项和请求，不要编造损坏原因或维修金额。” | 草稿是否保留未知事项，没有把推测写成已经证明的事实 |
| 模拟法庭 | 粘贴完整案情，选择文字模式开始 | 观察不同角色如何陈述、反驳和追问证据；这里是模拟练习，不是实际庭审 |

**案例要求：**至少保留合同、押金支付、退租交付、房屋状态和扣款依据这五类信息。体验时可以故意删去“退租照片”，观察页面是否提示证据不足；不要自行补造维修报价或损坏责任。

## 案例二：合同审查

进入 **合同审查**，直接点页面里的 **“体验示例合同审查”**，无需准备文件。示例是高风险劳动合同。操作后查看合同条款、风险说明与修改建议，尤其留意单方调岗、加班费、试用期社保、工资发放和解除条件等条款。

如果改用自己的文件，页面接受 PDF、Word 和 JPG/PNG 图片。请先确认文件可以由你提供，并遮盖与审查无关的身份证号、银行卡号等信息。**案例要求**是：合同条款可读、你能指出最关心的条款，并在结果中核对原条款、风险原因和修改建议是否对应。

## 案例三：劳动争议案件工作台

想看“一个问题如何持续办理”，可进入顶部 **案件与纠纷 → 案件工作台**。工作台依次展示 **目标与法域 → 材料整理 → 事实与证据 → 分析与文书**。下面是完全虚构的加班费案例。

创建案件时输入：

> 我想核查2026年6月的加班费，整理相关事实和证据，并了解能否形成仲裁申请草稿。

在“材料整理”中粘贴：

```text
【完全虚构的体验案例】
申请人是测试劳动者甲，用人单位是虚构云帆软件有限公司，实际工作地点在北京市朝阳区虚构测试园区。申请人于2025年3月1日入职，最近十二个月平均月工资8700元，实行每天8小时、每周5天的标准工时制，目前劳动关系仍继续。

2026年6月，单位安排申请人工作日延时加班10小时、休息日加班8小时、法定节假日加班4小时；休息日未安排补休。单位已支付加班补贴500元，其余加班费尚未支付。申请人于2026年6月30日知道当月加班费未足额支付。争议类型为加班费，请求核查并支付欠付部分。

可供进一步核对的材料线索有劳动合同、考勤记录、排班记录、工资条和银行流水；本段文字不代表这些文件已经上传。
```

**案例要求：**确认中国法域；逐项核对材料提出的候选信息和原文；在表单中检查入职日期、工资、工作地点、权利受损日期、争议类型、请求、工时制度及三类加班小时。缺项时如实补充，不要猜。按这组演示数字，三类加班费参考合计为 2150 元，扣除已付 500 元后预计欠付 1650 元；页面结论、依据和风险仍需逐项核对。只有你明确确认后，平台才应生成仲裁申请草稿；导出草稿不代表已提交仲裁。

## 案例四：图谱与辅助工具

- **法律图谱：**打开“法律图谱”，先浏览或搜索现有图谱。若体验账号允许创建，可用“租赁押金争议演示”作为图谱名称，将“合同约定”“押金支付”“退租交付”“损坏主张”作为待核对的概念节点，观察节点及关系怎样呈现。不要把演示节点写成确定法律结论。
- **法律计算器：**可用案例三的 8700 元月工资体验劳动补偿相关输入，也可以选利息或交通事故计算；不同页面的参数和计算口径不同，先看页面说明再填写。
- **法律日历与诉讼时效查询：**可用案例一的签约日和退租日练习记录时间，或输入页面要求的日期做查询。日期演示不等于确认真实案件的法定期限。
- **各类费用工具：**选择诉讼费、仲裁费等具体工具，按表单填写标的金额等参数，查看参考估算；正式费用以适用机关和现行标准为准。

## 如果用自己的案例，需要准备什么？

| 你想体验的功能 | 最少准备的信息 |
| --- | --- |
| 咨询、案情分析、相似案件解释 | 谁与谁发生争议、何时何地、发生经过、双方各自说法、想解决什么 |
| 合同审查 | 可阅读的合同文件，以及最关注的具体条款 |
| 纠纷整理、纠纷中心、案件工作台 | 上述事实加上证据线索；涉及金额或时间计算时，准备准确数值和日期 |
| 文书起草、合同起草 | 文件类型、用途、参与方、关键事实、必须写入的要求和未知事项 |
| 模拟法庭 | 争议经过、双方主张、主要证据；先选择文字模式即可体验 |
| 图谱和计算工具 | 想整理的概念关系，或对应工具要求的日期、金额、比例等参数 |

如实写“不清楚”或“尚无材料”，比补造事实更有用。上传真实材料前，请确认你有权提供，并处理无关的个人敏感信息。

## 体验完成后怎样反馈？

告诉我们你用了哪个功能和案例、完成了哪一步、页面实际显示了什么，以及你期待看到什么。如果某一步提示资料不足、处理失败或需要人工核对，请一并记录提示内容。

平台生成的问答、检索、分析、估算和文书仅供辅助参考。真实案件的事实、适用法律与正式文件应由专业人员核查；模拟法庭不是真实庭审。
